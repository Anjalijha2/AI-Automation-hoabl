## Live-portal mutation guard (CLAUDE.md Pipeline Discipline #7)
Every Config "Submit"/"Update"/"Save" changes LIVE config or cancels LIVE bookings/registrations. Per the rule, save/destructive TCs are authored as OPEN-section-assert-without-saving where the assertion can be made on the un-saved UI state (e.g. ADM_CFG_005 toggle-without-save, ADM_CFG_070 control inventory, ADM_CFG_038/039 read-only state, ADM_CFG_043 current-value read). All flows that require an actual save/upload/cancel are marked `[TEST_DATA_REQUIRED]` and require explicit user authorisation before execution.
