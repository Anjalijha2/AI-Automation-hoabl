# SM Portal — Overview

The Sales Manager Portal is the field-facing tool used by Sales Managers and Sales Manager Admins to assist buyers during Physical Event allocations, manage callback requests from the Buyer Portal, record video call (VC) outcomes, and track meeting schedules via Microsoft Teams integration.
