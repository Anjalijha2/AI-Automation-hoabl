## Admin Portal Summary

**URL:** `https://uat-web.xrportal.in/admin`
**Roles:** Admin (role_id = 1), SM Admin (role_id = 4)
**Auth:** Email + password

---

## Modules

| Module | Purpose |
|--------|---------|
| Login | Email/password auth for admin and SM Admin |
| Customers | View all buyer registrations, KYC status, unit bookings, home loan, milestones |
| Towers | Manage tower and unit inventory; view live heatmap |
| Allocation | Create and manage allocation campaigns (STATIC / DYNAMIC / PHYSICAL_EVENT) |
| Channel Partners | Manage CP accounts, approve/reject, assign SMs, bulk upload |
| Sales Managers | Manage SM accounts, availability, bulk upload |
| Offers | Create and manage discount offers; view applied offers per buyer |
| Payment Transactions | View all payment records; filter by status, type, date; export XLSX |
| JBP Management | Manage JBP cycles; review CP submissions and edit requests |
| Config CMS | Bulk uploads, system settings, payment gateway config, allocation masking |
